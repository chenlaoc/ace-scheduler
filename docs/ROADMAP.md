# 路线图

本页记录已确认的下一阶段目标和后续候选方向，不承诺具体发布时间。v1.5.0 实现与验证边界见 [实现记录](DAILY_USABILITY.md)，实际 UAC 安全桌面、Explorer 重启与系统睡眠仍需人工环境验收。接手上下文、代码位置与验收要求见 [下一阶段交接](HANDOFF.md)。

| 状态 | 方向 | 完成条件 |
| --- | --- | --- |
| 已实现 | 批量策略、实时监控、前后对照、恢复 | 启动仅观察、逐项回读、失败明确可见 |
| 已实现 | 应用内窗口框架和统一品牌 | 原生拖动/缩放、Logo 和打包身份一致 |
| 已发布（v1.5.0） | 恢复记录与异常会话处理 | 修改前可靠保存原值，重新启动后核验实例并由用户选择恢复，部分失败可重试 |
| 已发布（v1.5.0） | 托盘与应用生命周期 | 隐藏/真正退出语义明确，第二实例唤醒窗口，后台维护与恢复退出保持一致 |
| 已发布（v1.5.0） | 启动时申请管理员权限 | 普通启动先申请 UAC，取消即结束启动；授权后操作无需重复点击，显式只读模式不提权 |
| 已发布（v1.5.0） | 诊断导出与关于页面 | 异常明确可见，诊断脱敏，版本/反馈/目录/许可入口完整 |
| 后续阶段 | 安装、更新、签名 | 安装卸载和配置迁移可靠，更新来源可验证、失败可回退；签名主体另行确定 |
| 已发布（v1.5.0） | 亮色、暗色与自适应主题 | 设置即时生效、自动保存，自适应响应系统主题变化；覆盖自绘控件与对话框 |
| 后续阶段 | 可访问性 | 高对比度、键盘焦点、屏幕阅读器和文字缩放经过验证 |
| 待评估 | 更多机器与系统验证 | 多屏 DPI、不同 Windows 构建及实际 Processor Group 机器的证据 |
| 待评估 | 可靠的 CPU 拓扑分组 | 基于官方效率等级/API，不从编号猜测 P/E 核 |
| 待评估 | 配置导入/导出 | 校验、预览、明确应用范围和失败回退 |
| 待评估 | 长时记录与对照改进 | 有界资源消耗、可复现实验口径、明确数据保留策略 |

服务管理、驱动修改、进程结束/挂起、注入与反作弊绕过不属于项目方向。
