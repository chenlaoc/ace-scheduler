# 路线图

本页记录已确认的下一阶段目标和后续候选方向，不承诺具体发布时间。接手上下文、代码位置与验收要求见 [下一阶段交接](HANDOFF.md)。

| 状态 | 方向 | 完成条件 |
| --- | --- | --- |
| 已实现 | 批量策略、实时监控、前后对照、恢复 | 启动仅观察、逐项回读、失败明确可见 |
| 已实现 | 应用内窗口框架和统一品牌 | 原生拖动/缩放、Logo 和打包身份一致 |
| 下一阶段，未实施 | 恢复记录与异常会话处理 | 修改前可靠保存原值，重新启动后核验实例并由用户选择恢复，部分失败可重试 |
| 下一阶段，未实施 | 托盘与应用生命周期 | 隐藏/真正退出语义明确，第二实例唤醒窗口，后台维护与恢复退出保持一致 |
| 下一阶段，未实施 | 按需提权 | 普通启动可观察和编辑，需要写入时再请求权限；取消和接管失败不丢状态 |
| 下一阶段，未实施 | 诊断导出与关于页面 | 异常明确可见，诊断脱敏，版本/反馈/目录/许可入口完整 |
| 后续阶段 | 安装、更新、签名 | 安装卸载和配置迁移可靠，更新来源可验证、失败可回退；签名主体另行确定 |
| 后续阶段 | 系统主题与可访问性 | 高对比度、键盘焦点、屏幕阅读器和文字缩放经过验证 |
| 待评估 | 更多机器与系统验证 | 多屏 DPI、不同 Windows 构建及实际 Processor Group 机器的证据 |
| 待评估 | 可靠的 CPU 拓扑分组 | 基于官方效率等级/API，不从编号猜测 P/E 核 |
| 待评估 | 配置导入/导出 | 校验、预览、明确应用范围和失败回退 |
| 待评估 | 长时记录与对照改进 | 有界资源消耗、可复现实验口径、明确数据保留策略 |

服务管理、驱动修改、进程结束/挂起、注入与反作弊绕过不属于项目方向。
