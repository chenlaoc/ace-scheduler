# 日常可用性实现记录

原交接基线为 v1.4.0；本文件记录后续分阶段实现。仓库保持私有，未发布新版或移动标签。

## A. 恢复记录和退出（Issue #1）

`recovery.json` 保存在原配置目录，schema 1，包含系统启动时间、会话、PID/创建时间/名称，以及逐字段原值、最近写入值和确认状态。每次修改前使用同目录临时文件、flush/fsync、原子替换保存；记录失败则不执行该字段的新修改。写后回读并保存确认状态。

重新打开只观察。设置页提供安全恢复、明确覆盖冲突恢复，以及保留现值并归档记录三种入口。未确认写入和外部修改默认视为冲突；已恢复字段从记录移除，失败可重试。正常选择保留退出会归档记录；只读退出保留恢复机会。损坏/未知版本记录禁止新的写入，必须由用户明确归档；跨系统重启或超过 30 天的有效记录归档，不跨实例恢复。归档文件只保留证据，不自动再次加载。

退出弹窗防重入，排队操作与恢复继续等待后台回执；退出记录保存失败时窗口保留。原始恢复数据不会出现在 Git 或诊断导出中。

验证：117 项 Windows 本地回归通过（包含真实自建协作进程的跨会话恢复）；只读 smoke 和页面预览通过。证据在 `artifacts/recovery-smoke`、`artifacts/recovery-preview`。不承诺崩溃瞬间自动恢复，也不承诺抵御存储硬件未兑现刷盘的故障。
